## 1. Replace the hand-run frontier cells with API calls — **do this first**

**The problem.** §6.1 states that `gpt-5.6-sol` and `claude-opus-5` had no API
key in our environment, that every one of their cells came by hand through a
chat interface, and that the effort settings are vendor labels rather than
versioned artefacts. The abstract's 0.918, the Stratum-B exactness, and both top
rows of the downstream table all come from those two. Meanwhile §10 says
everything is regenerated by `verify_paper.py` — which regenerates the *scoring*
of a cached transcript, not the transcript. An action editor will spot the
tension.

**Scope.** 216 cells: 108 per model, C1/C2/C6/C9, 15 datasets.

**Cost**, measured by `api_cost.py` from the real prompts and stored
completions, not estimated:

| | cells | $ low | $ high |
|---|---|---|---|
| `claude-opus-5` max | 108 | 19.63 | 51.83 |
| `gpt-5.6-sol` xhigh | 108 | 6.92 | 18.34 |
| **all** | 216 | **27** | **70** |
| Stratum B only | 70 | 18 | 49 |

Budget **$150** for retries and parse failures. The band is reasoning tokens,
which neither model emits into the transcript and both bill for; entered as an
explicit 3×–8× multiplier rather than hidden in a point estimate.

**The funding constraint.** The available budget is ~₹28,000 of **Google Cloud**
credit, ADC only, no API keys. That buys two of three things:

| | via | GCP credit? |
|---|---|---|
| `gemini-*` refill | Vertex AI | ✅ real quota, no free-tier 429s |
| `claude-opus-5` | Vertex AI Model Garden | ✅ Anthropic models are served there |
| `gpt-5.6-sol` | — | ❌ **no amount of GCP credit buys OpenAI** |

**Therefore the plan**: run `claude-opus-5` through Vertex; leave `gpt-5.6-sol`
hand-run and disclosed. Opus's C1 figure of **0.905 is already the abstract's
headline**, and opus has its own Stratum B cells (35 of its 108), so the paper
gets a fully API-reproducible frontier model carrying the headline while gpt's
exactness becomes a corroborating same-day observation a reader cannot re-run.

**A side benefit worth the trouble.** On Vertex you pass an explicit
thinking-token budget as an integer against a pinned publisher model ID, not a
marketing effort label. That is a *better* answer to the "vendor labels rather
than versioned artefacts" complaint than an Anthropic-direct key would give.

**Price the risk before spending.** Re-running may *move* the numbers. The exact
84/0/0 was a hand run on a given day. If the API run returns 0.94 instead of
1.000, the paper reports the API run — reproducible beats flattering — and the
headline changes.

**Setup.** `gcloud` is not preinstalled; Vertex endpoints are reachable
(verified `server: ESF` through the proxy). No browser in a remote container, so
run `gcloud auth application-default login --no-launch-browser` on the local
machine. Before starting, confirm in the console: (a) Claude Opus is **enabled
in Model Garden** for the project — it needs a one-time click-through per model;
(b) the **exact publisher model ID**. Do not guess a version string.

## 2. Spend the surplus on shuffles for the headline model

₹28,000 is ~$320 and the job above needs ~$52. §8 currently concedes that most
models have one shuffle on Stratum A and that single-shuffle figures should not
be read to three decimals, given a measured spread up to 0.380.

Running `claude-opus-5` at **five shuffles** instead of one is roughly
$100–260 — affordable — and retires that limitation for the model carrying the
headline. Do this only after item 1 succeeds.

## 3. The seven missing `gemini-3.5-flash` cells

KOI C1/C2/C7, LC C1/C6, STUDENT C1/C6. Two honest endings, and the second is not
a failure:

- **Fill it** via Vertex, which has real quota. Note the underlying cause is not
  quota: at `temperature=0.0` the model returns `finish_reason: "length"` after a
  few hundred visible tokens regardless of budget, and KOI is the prompt that
  triggers it. More quota buys more attempts at a call that fails for another
  reason.
- **Drop the model** to an appendix. `gemini-3.7-flash` already represents that
  lab. Costs a few hours of regeneration and re-pinning because several
  aggregates shift.

Try the fill for one session; drop if it does not clear. Carrying a daggered row
through eight tables is a referee magnet.

**Do not substitute another model.** The row measures *that* model; filling it
with `gemini-3.7-flash` is a different experiment, not a refill.
